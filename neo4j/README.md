# Neo4j export

The browser viewers do not require Neo4j. `import_osteoclast_kg.cypher` is generated by `python -m src.kg.rebuild` from the audited canonical tables.

Import into an empty database. For an existing database, review/back up its content before explicitly choosing the loader's `--reset` option. Old ID nodes and old enrichment properties can otherwise remain present. The repair did not connect to a live Neo4j instance.

Nodes use `:Node:Protein`, `:Node:RNA`, `:Node:Gene` and other biological labels. Enzyme and transcription-factor roles add labels alongside Protein. Edges carry stable `edge_id`, review status and context references. `:Evidence`, `:Source`, `:Experiment` and `:Context` retain provenance; evidence identifies its claim by `edge_id` and cites source/experiment nodes. Pending and quarantined records are explicitly labeled for curation.

`enrich_nodes.cypher`, `deduplicate_edges.cypher` and `remove_drug_nodes.cypher` are retired no-ops. Use the full import; do not run the historical property-enrichment pipeline.

A structural PASS does not certify mechanisms. Review `../reports/SCHEMA_AND_PROVENANCE_REPAIR.md` before using these claims for scientific inference.
